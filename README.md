# Grill Planner

Splatoon 3 サーモンラン「グリル発進」の出現位置等をシミュレートする非公式の戦略支援ツール。

🔗 https://eoforgu0.github.io/grill-planner/

## 開発

```bash
npm install
npm run dev      # 開発サーバー
npm run build    # 本番ビルド
npm test         # テスト
```

React 19 + TypeScript + Vite + Tailwind CSS。
