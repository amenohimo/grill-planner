# 06 UIデザイン仕様

旧プロジェクトにはなかった文書。タイムラインの寸法、マーカーの視覚仕様、操作仕様、配色を事前に定義し、実装時の曖昧さを排除する。

---

## 1. 全体レイアウト

### 1.1 画面構成

```
┌─────────────────────────────────────────────────────────────┐
│  Header（タイトル + ファイル操作）                    固定高さ 48px │
├─────────────────────────────────────────────────────────────┤
│  SettingsBar（常時表示・折りたたみなし）                      │
│  ┌─ HazardLevelInput ─┐  表示 / 方面カラー / ズーム横・縦      │
│  └────────────────────┘                                    │
│  ┌─ MemoSection「詳細」（折りたたみ・初期は閉） ───────────┐  │
│  │  コード  タマヒロイ  方面名×3  ブキ×4  SP×4  自由メモ  │  │
│  └────────────────────────────────────────────────────┘  │
├─────────────────────────────────────────────────────────────┤
│  MainArea（横並び・各ペイン独立スクロール）                  │
│  ┌─ 左ペイン（設定+Timeline） ─────────┐┌─ 右サイドバー ──┐ │
│  │  方面ラベル │ 時間軸 │ A枠 │ B枠    ││  DirectionStats  │ │
│  │  （縦列）   │（縦軸）│レーン│レーン   ││  TargetOrder     │ │
│  │            │       │（縦）│（縦）   ││                  │ │
│  │  上=100s ──────────────────→       ││                  │ │
│  │  下=0s   ──────────────────→       ││                  │ │
│  └────────────────────────────────────┘└─────────────────┘ │
└─────────────────────────────────────────────────────────────┘
```

### 1.2 レイアウト方針

- 画面全体は縦フラックス（Header 固定 + MainArea）。MainArea は左ペインと右サイドバーの横並び
- 左ペイン: 残り幅を占有（flex-1）。設定バーとタイムラインを内包し独立スクロール
- 右サイドバー: 固定幅（最大 320px / `max-w-80`）。独立スクロール。方面別統計とターゲット順を縦に配置
- Timeline 内部は横並び（flex row）: 方面ラベル列 | 時間軸列 | レーン列（A枠・B枠が横並び）

### 1.3 折りたたみ

設定バー（キケン度・表示モード・方面カラー・ズーム）は常時表示で折りたたみ不可。折りたたみ可能なのは MemoSection（「詳細」セクション）のみで、初期状態は閉じている。展開するとシナリオコード・タマヒロイ方向・方面名プリセット・ブキ/SP 選択・自由メモを表示する。

## 2. 配色

### 2.1 カラーパレット

```css
@theme {
  /* ベース */
  --color-bg: #f8fafc;           /* 全体背景 slate-50 */
  --color-surface: #ffffff;       /* カード背景 */
  --color-border: #e2e8f0;        /* 境界線 slate-200 */
  --color-text: #1e293b;          /* 本文 slate-800 */
  --color-text-muted: #64748b;    /* 補助テキスト slate-500 */

  /* 枠カラー */
  --color-slot-a: #ef4444;        /* A枠 red-500 */
  --color-slot-a-light: #fecaca;  /* A枠 淡色 red-200 */
  --color-slot-a-bg: #fef2f2;     /* A枠 背景 red-50 */
  --color-slot-b: #3b82f6;        /* B枠 blue-500 */
  --color-slot-b-light: #bfdbfe;  /* B枠 淡色 blue-200 */
  --color-slot-b-bg: #eff6ff;     /* B枠 背景 blue-50 */

  /* マーカー */
  --color-spawn: #22c55e;         /* 湧き点 green-500 */
  --color-defeat: #f97316;        /* 撃破点 orange-500 */
  --color-defeat-hover: #ea580c;  /* 撃破点ホバー orange-600 */
  --color-defeat-drag: #c2410c;   /* 撃破点ドラッグ中 orange-700 */
  --color-defeat-invalid: #a3a3a3;/* 撃破点 不正位置 neutral-400 */

  /* 方面帯（方面IDごとの固定3色。デフォルト値。カラーテーマで上書きされる） */
  --color-dir-0: #fdf2f8;
  --color-dir-1: #fefce8;
  --color-dir-2: #ecfeff;

  /* リスポーン接続線 */
  --color-respawn-line: #a3a3a3;  /* neutral-400 */
  --color-spawner-decision: #facc15; /* スポナー決定マーク yellow-400 */

  /* インタラクション */
  --color-primary: #3b82f6;       /* ボタン等 blue-500 */
  --color-primary-hover: #2563eb; /* blue-600 */
  --color-danger: #ef4444;        /* 削除等 red-500 */
}
```

### 2.2 配色ルール

- A枠関連は赤系、B枠関連は青系で統一
- 湧き点（計算結果）は緑、撃破点（ユーザー操作）はオレンジ
- 方面帯は低彩度の淡色。コンテンツの可読性を妨げない
- 方面の色は方面ID（0/1/2）ごとに固定。同じIDの方面は必ず同色になる
- 方面帯の3色はカラーテーマセレクタ（「花」「パステル」「霞」）で切り替え可能。選択値は `--color-dir-0/1/2` を CSS 変数として上書きし、`localStorage` に保存される（`useColorTheme`）

## 3. タイムライン仕様

### 3.1 寸法

定数は `src/components/Timeline/coordinates.ts` に定義。下表の値は等倍（ズーム100%）時のもの。

| 項目 | 定数名 | 値 | 根拠 |
|------|--------|-----|------|
| PIXELS_PER_SECOND | `PIXELS_PER_SECOND` | 16 | 旧実装(8)の2倍。1秒あたり16pxで十分な操作精度を確保 |
| タイムライン全高 | `TIMELINE_HEIGHT` | 1600px | 100秒 × 16px |
| 上下パディング | `TIMELINE_PADDING` | 12px | 上下端の余白 |
| 方面ラベル列幅 | `DIRECTION_LABEL_WIDTH` | 56px | 方面名テキスト表示に十分 |
| 時間軸列幅 | `TIME_AXIS_WIDTH` | 28px | 目盛り + ラベル |
| 枠レーン幅 | `LANE_WIDTH` | 240px | マーカー + フキダシ（時刻・方面・ターゲット）+ 余白 |
| マーカー直径 | `MARKER_SIZE` | 14px | クリック・ドラッグ操作に十分な大きさ |
| マーカー中心位置 | `MARKER_CENTER_RATIO` | 1/3 | レーン左から1/3の位置にマーカー軸を配置 |
| 活動期間バー幅 | `ACTIVITY_BAR_WIDTH` | 8px | マーカー軸上に配置 |
| レーン間スペース | `LANE_SPACING` | 4px | 視覚的分離 |

タイムライン全体の幅: 56 + 28 + 240 + 4 + 240 = 568px（B枠あり、等倍時）

### 3.1.1 ズーム

横方向（`scaleX`）・縦方向（`scaleY`）のズーム倍率を独立して掛けられる。設定バーの「ズーム 横／縦」セレクタで `50% / 75% / 100% / 150% / 200%` から選択（`ZOOM_OPTIONS`）。各倍率は `localStorage` に保存される（`useZoom`）。

- 上記の寸法・座標は `scaleX` / `scaleY` を乗じて描画される（`scaledFrameToPixelY` など）
- マーカー・フォントなどには最小サイズの下限を設けて、縮小時でも視認性を確保する

### 3.2 スクロール

左ペイン（設定 + タイムライン）と右サイドバーはそれぞれ独立して `overflow-y: auto` で縦スクロールする。画面の高さに収まらないタイムラインを操作可能にする。

水平方向のスクロールは左ペインの横幅に依存する（ズーム拡大時は左ペインのスクロールで対応）。

### 3.3 時間軸（TimeAxis）

- 上端 = 100秒（ゲーム開始）、下端 = 0秒（ゲーム終了）
- 主目盛り（major, 10秒ごと）: 右寄せの濃い横線（幅12px）+ ラベル（`{秒}s`）
- 副目盛り（minor, 5秒ごと）: 右寄せの短い横線（幅8px, ラベルなし、薄色 text-muted）
- 補助目盛り（micro, 1秒ごと）: 右寄せの極短い横線（幅4px, ラベルなし、border 色）。ドット線ではなく短い実線
- マウスホバー時: カーソル位置の秒数を 0.1 秒単位でリアルタイム表示（フローティングラベル）

### 3.4 方面帯（DirectionBands）

各方面区間を全レーンにまたがる横帯として背景描画する。

- 帯の色: 方面IDに対応する `--color-dir-0/1/2` を使用（`getDirectionColor`）
- 境界: 2区間目以降の上端に 1px の破線（`border-top: 1px dashed`）
- 透過度: 不透明（CSS 変数の色をそのまま `backgroundColor` に適用）。色自体が低彩度の淡色のため、レーン内容の可読性は確保される

### 3.5 方面ラベル（DirectionLabels）

タイムライン左端の縦列に、各方面区間の方面名（プリセット名）を区間の高さいっぱいの帯として表示する。背景色は方面帯と同色。

- 各区間の中央に方面名を表示（プリセット名、未設定時は `方面{N}`）
- 区間にマウスホバーすると、方面（0/1/2）を選択するための ButtonGroup（3プリセット）がフロート表示される
- ButtonGroup の選択肢をクリックすると、その区間の方面IDが切り替わる（`UPDATE_DIRECTION`）。インラインのテキスト入力ではない
- 方面名そのもの（プリセット文字列）の編集は MemoSection「詳細」内の「方面名」入力欄で行う（最大10文字 × 3プリセット）
- フロートは領域外にカーソルが出ると（マージン 8px）自動的に閉じる

## 4. マーカー仕様

### 4.1 湧き点マーカー（SpawnMarker）

| 属性 | 値 |
|------|-----|
| 形状 | 円（●） |
| 直径 | `MARKER_SIZE` = 14px（最小8px） |
| 色 | `--color-spawn`（緑） |
| 枠線 | 1px solid `--color-border` |
| ラベル（フキダシ） | マーカー右側に `{秒}s {方面名}({方面内通し番号})` を半透明背景付きで表示。ターゲット表示があり表示モードが icon 以外ならターゲットラベル（例 `1P`）も付記 |
| ターゲットアイコン | フキダシの右外に、表示モードが text 以外のときブキアイコンを独立背景付きで表示 |
| 操作 | なし（読み取り専用） |

抑制された湧き（`isSuppressed`）は、緑のストライプ（repeating-linear-gradient）で塗り分けて区別する。枠レーンは `A`→赤、`B`→青のボーダーで区別する（マーカー枠線ではなくレーン上端の 3px ボーダー）。

### 4.2 撃破点マーカー（DefeatMarker）

| 属性 | 値 |
|------|-----|
| 形状 | 角丸四角を45度回転した菱形（◆） |
| サイズ | `MARKER_SIZE` = 14px × 14px（最小8px、`border-radius: 3`） |
| 色（通常） | `--color-defeat`（オレンジ）、`cursor: grab` |
| 色（ホバー） | `--color-defeat-hover` |
| 色（ドラッグ中・正当） | `--color-defeat-drag` + `cursor: grabbing` + 影 |
| 色（ドラッグ中・不正） | `--color-defeat-invalid` + 破線枠 |
| 枠線 | 1px solid `--color-border`（不正ドラッグ時は dashed） |
| 連動ハイライト | Shift+ホバー時、影として `0 0 0 2px rgba(59,130,246,0.4)`（後続撃破の連動移動対象を示す） |
| 連動プレビュー | 連動移動中の対象は半透明（opacity 0.5） |
| ラベル | マーカー右側に撃破時刻 `{秒}s` を半透明背景付きで表示。クリックで数値入力に切り替え（時刻の直接編集） |
| 操作 | ドラッグで時間移動、Shift+ドラッグで後続も連動移動、右クリックで削除、ラベルクリックで時刻入力（Enter 確定 / Shift+Enter で連動 / Escape 取消） |

### 4.3 リスポーン接続線（RespawnConnector）

撃破点から湧き点への視覚的な接続。

```
[撃破◆]
   │ 実線
   │ 184F(3.07秒)
[●スポナー決定]
   ┊ 破線
   ┊ 30F(0.5秒)
[●湧き]
```

SVG（`<line>` + `<circle>`）で描画する。撃破点・湧き点と同じ X 軸（レーン左から `MARKER_CENTER_RATIO`）上に縦線を引く。

| 属性 | 値 |
|------|-----|
| 線種 | 実線（撃破→スポナー決定）+ 破線（`strokeDasharray="4 3"`, スポナー決定→湧き） |
| 線幅 | 1px（`scaleX` を乗算、最小0.5px） |
| 色 | `--color-respawn-line` |
| スポナー決定マーク | 小さな円（半径 `markerSize * 0.25`）、塗り `--color-spawner-decision`、枠 `--color-respawn-line` |
| 表示条件 | 撃破由来の湧き点のみ（`!isAuto && defeatId` を持つもの。自動湧きは非表示） |

### 4.4 活動期間バー（ActivePeriod）

グリルが存在している期間を、マーカー軸（レーン左から `MARKER_CENTER_RATIO`）上に縦バーで表示。

| 属性 | 値 |
|------|-----|
| 幅 | `ACTIVITY_BAR_WIDTH` = 8px（`scaleX` 乗算、最小4px） |
| 位置 | マーカー軸上（中央寄せ） |
| 色 | 枠カラーの淡色版（A: `--color-slot-a-light`, B: `--color-slot-b-light`） |
| 角丸 | 2px |
| 範囲 | 湧き時刻（上端）→ 撃破時刻（下端）。未撃破なら0秒まで延長 |

### 4.5 経過時間ラベル（ElapsedTimeLabel）

湧き点と撃破点のペアについて、その間の経過秒数（湧き→撃破までの時間）をマーカー軸の左側、区間中央に表示する。

| 属性 | 値 |
|------|-----|
| 表示 | `{経過秒}s`（0.1秒単位） |
| 位置 | マーカー軸の左側、湧き〜撃破の中点 |
| 操作 | クリックで数値入力に切り替え、経過時間を直接編集できる（Enter 確定 / Shift+Enter で連動 / Escape 取消）。入力値から逆算して撃破時刻を更新する |

### 4.6 その他のタイムライン要素

- 操作説明 + 凡例: レーン領域の右外に常設の説明ボックスを表示（クリック/ドラッグ/Shift+ドラッグ/右クリックの操作、および湧き・撃破・スポナー確定・抑制湧きの凡例）
- B枠の無効エリア: B枠が開く前（`bSlotOpenFrame` より上）の領域を半透明グレーで覆う
- ファイルドラッグオーバー時: タイムライン全体に破線枠 + 「ドロップしてインポート」オーバーレイを表示

### 4.7 共通コンポーネント: ButtonGroup

セグメント化されたトグル/選択 UI（`src/components/ButtonGroup.tsx`）。選択肢を横並びボタン群として描画し、選択中の項目を primary 色で強調する。任意でアイコンを付与可能。表示モード切替・方面プリセット選択（方面ラベルのフロート）・ターゲット順の各行で再利用される。

## 5. 操作仕様

### 5.1 撃破点の追加

| 操作 | 動作 |
|------|------|
| レーン上でクリック | クリック位置の時刻・枠に撃破点を追加 |
| バリデーション | シミュレーション方式で妥当性を検証。不正な場合は追加しない |
| フィードバック | 追加不可の場合、カーソル位置に赤い「✕」を 500ms 表示してから消す |
| スナップ | 最小単位は1フレーム。UIの精度はPIXELS_PER_SECONDに依存 |

### 5.2 撃破点のドラッグ移動

| フェーズ | 動作 |
|---------|------|
| mousedown | ドラッグ候補として記録。移動距離カウント開始 |
| mousemove（5px未満） | まだドラッグ開始しない |
| mousemove（5px以上） | ドラッグ開始。マーカーの見た目をドラッグ状態に変更 |
| ドラッグ中 | マーカーがカーソルに追従。リアルタイムで湧き点・方面を再計算プレビュー |
| ドラッグ中 — 不正位置 | マーカーをグレー（`--color-defeat-invalid`）に変更 |
| mouseup — 正当位置 | 撃破点の時刻を確定。影響を受ける後続撃破点があれば削除 |
| mouseup — 不正位置 | 元の位置にスナップバック |
| Escape | ドラッグキャンセル、元の位置に戻る |

#### 5.2.1 連動移動（Shift）

| 操作 | 動作 |
|------|------|
| Shift+ドラッグ | 対象より後（frameTime が小さい）の同枠撃破点を、同じ差分で連動移動する |
| Shift+ホバー | 連動対象となる撃破点を青い外枠でハイライト表示（移動前のプレビュー） |
| 連動プレビュー | ドラッグ中、連動対象は半透明で移動先位置に表示される |
| バリデーション | 連動対象すべてが妥当（`0 < frameTime < 6000` かつ整合）な場合のみ確定 |
| 時刻入力での連動 | 撃破時刻ラベル / 経過時間ラベルの数値入力で Shift+Enter すると同様に連動移動 |

### 5.3 撃破点の削除

| 操作 | 動作 |
|------|------|
| 右クリック | コンテキストメニューではなく即座に削除 |
| 影響確認 | 削除により後続撃破点が不整合になる場合、それらも連動削除（`findCascadeRemovals`） |

> 連動削除時に削除対象を一瞬ハイライトする演出は**未実装**（連動削除は即座に実行される）。

### 5.4 方面（方面ID）の切り替え

各方面区間に割り当てる方面ID（0/1/2 のプリセット）を切り替える。

| 操作 | 動作 |
|------|------|
| 方面ラベルにホバー | 3プリセットの ButtonGroup がフロート表示される |
| プリセットをクリック | その区間の方面IDを切り替え（`UPDATE_DIRECTION`） |
| 領域外へ移動 | フロートが自動的に閉じる |

> 方面ラベルのインラインテキスト編集（Enter/Escape）は**廃止**。方面名そのもの（プリセット文字列）の編集は MemoSection「詳細」の「方面名」欄（最大10文字 × 3）で行う。

### 5.5 キケン度変更時の挙動

キケン度変更時の方面・撃破点の再生成と再検証については「7.5 キケン度変更時の挙動」を参照。

## 6. 右サイドバー仕様

右サイドバーには 2 つのコンポーネントを縦に配置する: 方面別統計テーブル（DirectionStatsTable）とターゲット順テーブル（TargetOrderTable）。

### 6.1 方面別統計テーブル（DirectionStatsTable）

```
┌────┬────────┬──────┬──────┐
│ #  │ 方面    │ 湧き  │ 撃破  │
├────┼────────┼──────┼──────┤
│ 1  │ 左      │  3   │  2   │
│ 2  │ 中央    │  2   │  2   │
│ 3  │ 右      │  4   │  3   │
├────┼────────┼──────┼──────┤
│    │ 合計    │  9   │  7   │
└────┴────────┴──────┴──────┘
```

- 列は「#（区間番号）」「方面（プリセット名、未設定は `方面{N}`）」「湧き数」「撃破数」
- 区間は時間順（1 = 最初の区間 = 100秒側）
- 合計行は太字。湧き合計は `totalGrillCount`、撃破合計は各区間の撃破数の和
- 同じ方面ID が複数区間に現れる場合、テーブル下部に「方面名別合計」（ID ごとに湧き・撃破を集約）を追加表示

### 6.2 ターゲット順テーブル（TargetOrderTable）

湧き順に対応するターゲット（どのプレイヤーが処理するか）を行ごとに割り当てる入力テーブル（最大25行）。

- 各行: 行番号 + ButtonGroup（`1P`〜`4P` + `-`）。ブキ選択済みプレイヤーはアイコン付きで表示
- 「▽1つ下にずらす」「△1つ上にずらす」ボタンで割り当て全体をシフト（`SHIFT_TARGET_ORDER`）
- 選択値はタイムラインの湧きマーカーのターゲット表示に反映される

## 7. 設定バー仕様

設定バーは左ペイン上部に常時表示される。左にキケン度入力、右にまとめて表示系トグル（表示モード・方面カラー・ズーム）、下に折りたたみ式の MemoSection「詳細」を配置する。

### 7.1 キケン度入力（HazardLevelInput）

- 数値入力（`type="number"`）: `MIN_HAZARD_LEVEL`〜`MAX_HAZARD_LEVEL` にクランプ
- 表示: 「キケン度: [____] %」形式（スライダーは無し）
- 変更時: 方面区間と撃破点の再検証が即座に実行される（7.5 参照）

### 7.2 表示系トグル

- 表示モード（DisplayModeToggle）: ButtonGroup で「アイコン / テキスト / 両方」を選択。`localStorage` 保存（`useDisplayMode`）
- 方面カラー: セレクトボックスで「花 / パステル / 霞」を選択（`COLOR_THEMES`）
- ズーム 横 / 縦: それぞれセレクトボックスで `50 / 75 / 100 / 150 / 200 %`（`ZOOM_OPTIONS`）

### 7.3 MemoSection「詳細」（折りたたみ）

「詳細」トグル（初期は閉）を開くと以下を表示する。

- シナリオコード: 正規化・自動ハイフン挿入（`Sxxx-xxxx-xxxx-xxxx`）+ バリデーション（不正時は枠を danger 色に）
- タマヒロイ方向: テキスト入力
- 方面名: 3プリセットのテキスト入力（各最大10文字）
- ブキ / SP 選択: プレイヤー4人分の表レイアウト。各セルにアイコン + セレクトボックス（マスターデータから動的生成、未選択 `--` 可）
- 自由メモ: 自動高さ調整の textarea（最大1000文字）

### 7.4 ファイル操作

- Header の「エクスポート」ボタン: シナリオを JSON でダウンロード。押下中は「エクスポート中...」、完了後 2 秒間「エクスポート完了」を表示
- Header の「インポート」ボタン: ファイル選択ダイアログから JSON を読み込み反映
- タイムラインへのファイルのドラッグ&ドロップでもインポート可能（ドラッグオーバー時に「ドロップしてインポート」オーバーレイを表示）
- エラー時: 画面上部に danger 色のバーでメッセージ表示（3秒で自動消失）
- 警告（インポート時の軽微な不整合）: 画面上部に primary 色のバーで表示（5秒で自動消失）

### 7.5 キケン度変更時の挙動

1. 方面区間を再生成（`generateDefaultDirections`）
2. 方面ID: 区間数が同じなら各区間の方面ID を保持、異なればデフォルトにリセット
3. B枠: B枠が消滅するキケン度（`bSlotOpenFrame < 0`）になった場合、B枠の撃破点を全削除
4. 撃破点: 再計算した湧きと突き合わせ、整合する湧きが無い撃破点を削除

## 8. レスポンシブ方針

本バージョンはデスクトップ専用。レスポンシブ対応は行わないが、以下を考慮:

- タイムラインは縦方向に1600px（等倍時）のコンテンツを持ち、縦スクロールで操作する
- タイムラインの幅は等倍で約568px（B枠あり時）。ズーム倍率に応じて伸縮し、左ペインの横スクロールで対応する
- MemoSection「詳細」を閉じることで、タイムラインの縦表示領域を確保できる

## 9. アニメーション

控えめなアニメーションで操作のフィードバックを強化する。

| 対象 | アニメーション | 値 | 実装状況 |
|------|-------------|-----|----------|
| マーカー追加 | フェードイン + スケール（`@keyframes marker-in`） | opacity 0→1 / scale 0.5→1, 150ms ease-out | 実装済み |
| 撃破マーカー色変化 | 背景色トランジション | background-color 0.15s（ドラッグ中は無効） | 実装済み |
| ドラッグ中マーカー | 影の追加 | `0 2px 8px rgba(0,0,0,0.3)` | 実装済み |
| Header ボタン | 押下スケール | `active:scale-95`, 100ms | 実装済み |
| エラーインジケータ（✕） | 500ms 後に DOM から除去 | 500ms | 実装済み |
| I/O エラー / 警告バー | 画面上部に表示し自動消失 | エラー3秒 / 警告5秒 | 実装済み |
| マーカー削除 | フェードアウト + スケール | — | 未実装（即時除去） |
| 折りたたみ開閉 | 高さアニメーション | — | 未実装（条件レンダリングで即時切替） |
| スライドイン式トースト | — | — | 未実装（I/O 通知は上部バー方式） |

`@keyframes marker-in` は `src/index.css` に定義。パフォーマンスを優先し、`transform` / `opacity` / `scale` 中心でアニメーションする。
